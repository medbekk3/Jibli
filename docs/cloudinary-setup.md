# إعداد Cloudinary لجيبلي

1. أنشئ حساباً أو مشروعاً في Cloudinary.
2. من إعدادات الرفع أنشئ Upload Preset غير موقّع مخصصاً للمشروع.
3. قيّد أنواع الملفات في الإعدادات إلى JPG وJPEG وPNG وWebP إن أمكن.
4. أضف القيم التالية إلى `.env.local`:

```env
NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=اسم_السحابة
NEXT_PUBLIC_CLOUDINARY_UPLOAD_PRESET=اسم_إعداد_الرفع
```

لا يحتاج الرفع غير الموقّع إلى API Secret، ولا يجب وضع API Secret في متغيرات تبدأ بـ `NEXT_PUBLIC_` أو في كود الواجهة.

يتحقق التطبيق محلياً من نوع الصورة ومن حد أقصى قدره 2 ميغابايت، ويعرض معاينة قبل الضغط على زر الرفع. تحفظ Firestore رابط الصورة ومعرّفها العام فقط.
