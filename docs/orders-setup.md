# إعداد نظام الطلبات

1. تأكد من ضبط متغيرات Firebase العامة ومتغيرات Firebase Admin في `.env.local`.
2. انشر قواعد Firestore والفهارس:

```text
firebase deploy --only firestore
```

3. يحتاج النظام إلى Collections التالية: `orders` و`counters`. ينشئهما الخادم تلقائياً عند أول طلب.
4. يجب أن تكون وثيقة الزبون `active` وبدور `customer`، ووثيقة المطعم نشطة ومفتوحة ومنتجاته متوفرة.
5. يجب ربط حساب المطعم عبر `restaurants.ownerId` حتى يتمكن من قراءة طلباته وتغيير حالاتها.

لا يحتاج نظام الدفع إلى أي إعداد؛ الطريقة الوحيدة هي الدفع نقداً عند الاستلام.
