# جيبلي

منصة عربية لطلب الطعام من مطاعم مدينة بريان.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## الهيكلة

- `src/app`: المسارات والتخطيطات العامة.
- `src/components`: مكونات الواجهة المشتركة.
- `src/features`: وحدات الأعمال المستقلة.
- `src/lib`: التكاملات والأدوات المشتركة.
- `src/types`: الأنواع المشتركة.
- `src/config`: إعدادات التطبيق الثابتة.

تم إعداد المشروع باستعمال نمط المسارات الحديث، وTypeScript بالوضع الصارم، وTailwind CSS، مع دعم العربية واتجاه RTL من الجذر.
